# Demo-day presentation

- `twin-date-slides.html`: the deck. Open it in Chrome, go full screen (Mac: Ctrl+Cmd+F), and move with the arrow keys or Space. Needs internet for the font.
- `script.md`: who says what on each slide, with timings (about 6:50 of 7 minutes) and a pre-demo checklist.

To edit: change the text in `twin-date-slides.html` directly (each slide is a `<section>`, its script is the `<!-- SCRIPT … -->` comment at the end), or press E in the browser, edit, and Cmd+S to download the edited file. Built with the [frontend-slides](https://github.com/zarazhangrui/frontend-slides) skill.
