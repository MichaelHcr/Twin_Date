# Twin Date

Your AI twin goes on the first chat for you, then hands you a shortlist of people worth meeting.

- Live: https://twin-date.vercel.app
- PRD: https://claude.ai/code/artifact/8ce785e9-b94b-461c-95a3-4070eb5cda3a

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in the values (see docs/HANDOFF.md)
npm run dev                  # http://localhost:3000
```
